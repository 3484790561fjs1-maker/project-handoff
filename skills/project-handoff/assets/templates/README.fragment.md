## 换电脑接着开发

两台电脑各安装一次 project-handoff Skill。新电脑克隆本业务项目，在 Codex 中打开项目文件夹并配置上面的开发环境。

- 开始时：`使用 $project-handoff，开工同步。`
- 结束时：`使用 $project-handoff，收工同步。`

架构、进展和重要决策的实际文档位置见 `.project-handoff.json`。具体项目规则见 `AGENTS.md`。
